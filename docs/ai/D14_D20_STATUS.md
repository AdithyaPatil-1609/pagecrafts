## D14 — ranking and art direction

`rankTemplates()` is the shared deterministic scorer used by template fallback
and gallery ranking. Its order is:

1. exact vertical: +100
2. category: +30
3. tone and palette: +10 each
4. shared requested section: +1 each
5. template id as a stable tie-break

The classify-to-gallery path now carries the vertical rather than discarding it,
and the generation runner retains the classified attributes for fallback. A
provider failure therefore selects the nearest template instead of the first id.

All eight registered themes are generated into provider schemas, prompt
variables, render tokens, and CSS from one registry. Tests pin registry
coverage and the art-direction render path.

## D16 — tuning and composition validation

`plan.v2` and `fill-section.v2` remain opt-in. Promoting them without a passing
before/after would violate the tuning rule (“pass rate up, zero regressions”).
The comparison command exits non-zero on regression or an unmatched case:

```bash
AI_PROMPT_PLAN=plan.v2 AI_PROMPT_FILL=fill-section.v2 \
  npm run grade -- --label=v2 --budget=400
npm run compare -- <v1-results-directory> <v2-results-directory>
```

The generation runner validates every assembled composition before completion.
It repairs motion over the 2,000 ms budget and records variant monotony,
adjacent repeats, and motion/theme mismatches without discarding a usable page.

## D17 and D20 — durable cost accounting

Every detached generation now:

- holds its concurrency slot until the job reaches a terminal state;
- records aggregate token spend against the daily cap;
- persists one priced row per provider invocation to `public.generations`;
- stores `job_id`, so two quick generations are never merged by a time heuristic;
- stores only a SHA-256 prompt hash, never prompt text.

The dashboard reads production rows by default and eval rows only when asked:

```bash
npm run cost
npm run cost -- --eval
npm run cost -- evals/grader/results/<run>
npm run cost -- --invoice=groq:120,gemini:40 --out=docs/ai/AI_SPEND.md
```

It reports cost per user and generation, provider/stage/model/version/day
slices, failed-call waste, unpriced providers, and invoice variance. A D20
number is valid only when production rows have non-zero current rate cards and
invoice reconciliation is within 5%.

## D18 — real-load command

The detached generate route no longer releases the request guard with the 202
response. `ai:caps` dispatches concurrent real requests, requires an explicit
confirmation, and fails if more than the configured concurrency cap are
accepted, a 5xx appears, no request is throttled, or a 429 lacks `Retry-After`.

```bash
AI_LOAD_TEST_URL=https://<host>/api/v1/projects/<test-project>/generate \
AI_LOAD_TEST_COOKIE='<dedicated-test-session-cookie>' \
npm run ai:caps -- --confirm
```

Use a dedicated beta test account: accepted requests invoke the configured
provider and consume quota.
