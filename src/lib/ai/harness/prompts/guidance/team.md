Only name people the description names. If it does not name anyone, write roles
rather than invented people — "Senior physiotherapist", not "Dr Anjali Menon".

Never write "Attorney Name", "Team Member", or the same dummy name twice.

An invented name on a real business's website is a problem the owner discovers
from a customer.

name ..... as given, spelled as given. If none was given, the role is the name.
role ..... the job, in the words this trade uses.
bio ...... one sentence: what they do here, and the one qualification or length
           of service that matters. No adjectives about passion. No invented
           years.
